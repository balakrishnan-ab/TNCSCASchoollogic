def binary_search(arr, target):
low = 0
high = len(arr) - 1
while low <= high:
mid = (low + high) // 2
if arr[mid] == target:
return mid # எண்கள் பொருந்தியதால் index திருப்பப்படும்
elif arr[mid] < target:
low = mid + 1 # வலது பக்கத்தில் தேடுதல்
else:
high = mid - 1 # இடது பக்கத்தில் தேடுதல்
return -1 # எண் கண்டுபிடிக்கப்படவில்லை
இயங்கும் போது எந்த வரி செயலில் உள்ளது என்பது சிறப்பித்துக் காட்டப்படும்.

பைனரி சர்ச் எப்படி வேலை செய்கிறது?

1

வரிசைப்படுத்துதல்: கொடுக்கப்பட்ட எண்கள் அனைத்தும் ஏறுவரிசையில் (Sorted Order) இருக்க வேண்டும்.

2

நடு எண்ணைக் கண்டறிதல்: ஆரம்ப எல்லை low மற்றும் முடிவு எல்லை high கணக்கிட்டு, நடு எண்ணை (mid) தேர்வு செய்யும்.

3

ஒப்பிடுதல்:

  • நடு எண் == தேடும் எண் எனில், வெற்றி!
  • தேடும் எண் > நடு எண் எனில், இடது பாதியைத் தவிர்த்து வலது பாதியில் தேடும் (low = mid + 1).
  • தேடும் எண் < நடு எண் எனில், வலது பாதியைத் தவிர்த்து இடது பாதியில் தேடும் (high = mid - 1).

4

வேகம் (Efficiency): ஒவ்வொரு அடியிலும் தரவு பாதி பாதியாக குறைக்கப்படுவதால், பெரிய தரவுகளுக்கு இது மிக வேகமானது (O(log n)).
