வரிசைப்படுத்தப்பட்ட தரவு (Sorted Array) Time: O(log n)

Python நிரல் (Source Code)

நேரலைக் கண்காணிப்பு
def binary_search(arr, target):
low = 0
high = len(arr) - 1
while low <= high:
mid = (low + high) // 2
if arr[mid] == target:
return mid # எண்கள் பொருந்தியதால் index திருப்பப்படும்
elif arr[mid] < target:
low = mid + 1 # வலது பாதியில் தேடுதல்
else:
high = mid - 1 # இடது பாதியில் தேடுதல்
return -1 # எண் கண்டுபிடிக்கப்படவில்லை
இயங்கும் வரி தானாக ஹைலைட் செய்யப்படும்.

பைனரி சர்ச் எப்படி வேலை செய்கிறது?

1

வரிசைப்படுத்துதல்: கொடுக்கப்பட்ட எண்கள் அனைத்தும் ஏற்கனவே ஏறுவரிசையில் (Sorted Order) அமைய வேண்டும்.

2

நடு எண்ணைக் கண்டறிதல்: ஆரம்ப சுட்டி low மற்றும் இறுதி சுட்டி high கூட்டி, சராசரியாக நடு இடத்தை (mid) தேர்வு செய்யும்.

3
ஒப்பீடு & சுருங்குதல்:
  • நடு எண் == தேடும் எண் எனில், உடனே வெற்றி!
  • தேடும் எண் > நடு எண் எனில் வலது பகுதி (low = mid + 1).
  • தேடும் எண் < நடு எண் எனில் இடது பகுதி (high = mid - 1).
4

நேர செயல்திறன்: ஒவ்வொரு அடியிலும் பரிசீலனைக்குரிய பாதியளவு எண்கள் நீக்கப்படுவதால் இதன் வேகம் O(log n) ஆகும்.
