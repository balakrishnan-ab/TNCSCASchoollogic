தேர்வு முறை (In-place Algorithm) Time: O(n²) Swaps: O(n) Space: O(1)

Python நிரல் (Source Code)

நேரலை வரி கண்காணிப்பான்
def selection_sort(arr):
n = len(arr)
for i in range(n - 1):
min_idx = i # தற்போதைய குறைந்த எண் சுட்டி
for j in range(i + 1, n):
if arr[j] < arr[min_idx]:
min_idx = j # புதிய குறைந்தபட்ச சுட்டி
if min_idx != i:
arr[i], arr[min_idx] = arr[min_idx], arr[i] # இடமாற்றம் (Swap)
return arr

தேர்வு வரிசையாக்கம் எப்படி இயங்குகிறது?

1

குறைந்தபட்ச எண்ணைத் தேர்வு செய்தல்: வரிசையின் வரிசைப்படுத்தப்படாத பகுதியில் இருந்து மிகச்சிறிய எண்ணைத் தேடி அதன் சுட்டியை (min_idx) குறித்துக் கொள்ளும்.

2

நேரியல் ஸ்கேனிங் (Scanning with j): சுட்டி j ஆனது i + 1 முதல் கடைசி வரை சென்று தற்போதைய குறைந்த எண்ணை விட சிறிய எண் உள்ளதா என ஒவ்வொன்றாக ஒப்பிடும்.

3

முன் பகுதிக்கு மாற்றுதல் (Swap at index i): முழு வரிசையும் சோதிக்கப்பட்ட பின், கண்டறியப்பட்ட மிகச்சிறிய எண் வரிசைப்படுத்தப்படாத பகுதியின் தொடக்க இடத்திற்கு (i) இடமாற்றம் செய்யப்படும்.

4

அதிநவீன செயல்திறன் (Low Memory Writes): குமிழி வரிசையாக்கம் போல ஒவ்வொரு ஒப்பீட்டிற்கும் இடமாற்றாமல், ஒரு சுற்றுக்கு அதிகபட்சமாக 1 முறை மட்டுமே இடமாற்றம் (Maximum $n$ swaps) செய்யும்.

நினைவகத்தில் எழுதும் செலவு (Memory writes) மிகவும் விலைமதிப்பற்றதாக இருக்கும் சாதனங்களில் Selection Sort மிகவும் சிறந்தது.
