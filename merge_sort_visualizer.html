நேரலை வரி கண்காணிப்பான்
def merge_sort(arr, left, right):
if left < right:
mid = (left + right) // 2 # நடுப்பகுதி பிரித்தல்
merge_sort(arr, left, mid) # இடது பகுதி
merge_sort(arr, mid + 1, right) # வலது பகுதி
merge(arr, left, mid, right) # ஒன்றிணைத்தல்
def merge(arr, left, mid, right):
L = arr[left:mid + 1]; R = arr[mid + 1:right + 1]
i = 0; j = 0; k = left
while i < len(L) and j < len(R):
if L[i] <= R[j]:
arr[k] = L[i]; i += 1
else:
arr[k] = R[j]; j += 1
k += 1
# மீதமுள்ள எண்களை சேர்த்தல் (Drain remaining)
while i < len(L): arr[k] = L[i]; i += 1; k += 1
while j < len(R): arr[k] = R[j]; j += 1; k += 1

இணைப்பு வரிசையாக்கம் எப்படி இயங்குகிறது?

1

பிரித்தல் (Divide): கொடுக்கப்பட்ட வரிசை ஒரு உறுப்பாக மாறும் வரை அதன் மையப்புள்ளி (mid = (left + right) // 2) வழியாக இரண்டு சம பாகங்களாகத் தொடர்ந்து பிரிக்கப்படுகிறது.

2

துணைப் பட்டியல்கள் (L & R): பிரிக்கப்பட்ட இடது பகுதி (L) மற்றும் வலது பகுதி (R) தற்காலிக நினைவகத்தில் சேமிக்கப்படுகின்றன.

3

ஒப்பிட்டு ஒன்றிணைத்தல் (Conquer & Merge): இரு பட்டியல்களின் முதல் எண்கள் ஒப்பிடப்பட்டு, சிறிய எண் முதன்மை வரிசையின் arr[k]-இல் வைக்கப்படுகிறது.

4

முழுமை பெறுதல் (Final Array): அனைத்து துண்டுகளும் வரிசையாக இணைக்கப்பட்டு, எப்போதும் உத்தரவாதமான O(n log n) வேகத்தில் முழு வரிசையும் வரிசைப்படுத்தப்படுகிறது!
