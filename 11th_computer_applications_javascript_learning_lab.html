Introduction to JavaScript

  • • 1995-ல் நெட்ஸ்கேப் (Netscape) நிறுவனத்தில் பிரெண்டன் ஐக் என்பவரால் உருவாக்கப்பட்டது.

Variables & Data Types

4 பாடம் 14

உரையாடல் பெட்டிகள்

Dialog Boxes (Alert, Prompt, Confirm)

  • • alert("செய்தி"): பயனருக்கு எச்சரிக்கை அல்லது செய்திப் பெட்டியைத் தோற்றுவிக்கும். இதில் 'சரி' (OK) பொத்தான் மட்டுமே இருக்கும்.
  • • prompt("உரை", "முன்னிருப்பு"): பயனரிடம் இருந்து உரை உள்ளீட்டைப் பெற உதவும்.
  • • confirm("கேள்வி"): பயனரின் சம்மதத்தைப் பெற உதவும் (OK எனில் true, Cancel எனில் false தரும்).

கிளைப்பிரிப்புக் கூற்றுகள்

Branching / Conditional Statements

  • • if கூற்று: நிபந்தனை மெய்யாக இருக்கும்போது மட்டுமே தொகுதி இயங்கும்.
  • • if...else: மெய் எனில் ஒரு தொகுதியும், பொய் எனில் மாற்று தொகுதியும் இயங்கும்.
  • • switch...case: பல தேர்வுகளில் இருந்து ஒரு குறிப்பிட்ட வழியைத் தேர்ந்தெடுக்க உதவும் (break கூற்றுடன் பயன்படும்).

function validateForm() {
    var name = document.getElementById("name").value;
    var mobile = document.getElementById("mobile").value;

    // 1. பெயர் காலியாக உள்ளதா என அறிதல்
    if (name == "") {
        alert("பெயர் காலியாக இருக்கக் கூடாது!");
        return false;
    }

    // 2. கைபேசி எண் 10 இலக்கங்கள் மற்றும் எண்களா என அறிதல்
    if (isNaN(mobile) || mobile.length != 10) {
        alert("சரியான 10 இலக்க கைபேசி எண்ணை உள்ளிடவும்!");
        return false;
    }

    alert("படிவம் வெற்றிகரமாக ஏற்றுக்கொள்ளப்பட்டது!");
    return true;
}
