11-ஆம் வகுப்பு கணினி பயன்பாடுகள் (Computer Applications)

ஜாவாஸ்கிரிப்ட் கற்றல் & செய்முறை களம்

ஜாவாஸ்கிரிப்ட் பாடப்பகுதி சுருக்கங்கள்

11-ஆம் வகுப்பு கணினி பயன்பாடுகள் பாடநூலின் அத்தியாயம் 14 & 15-ன் முக்கியக் கோட்பாடுகள் மற்றும் சூத்திரங்கள்.

அரசுத் தேர்வு பாடத்திட்டம்
1

ஜாவாஸ்கிரிப்ட் ஓர் அறிமுகம்

Introduction to JavaScript
  • • பிரெண்டன் ஐக் (Brendan Eich) என்பவரால் 1995-ல் உருவாக்கப்பட்டது.
  • • இது ஒரு கிளையன்ட் பக்க (Client-side) ஸ்கிரிப்டிங் மொழியாகும்.
  • • வலைப்பக்கங்களை செயல்மிக்கதாக (Dynamic & Interactive) மாற்ற உதவுகிறது.
  • • HTML கோப்பில் <script> ஒட்டின் மூலம் சேர்க்கப்படுகிறது.
2

மாறிகள் & தரவு வகைகள்

Variables & Data Types
  • • மாறிகள் var அல்லது let கொண்டு அறிவிக்கப்படும்.
  • • முக்கிய தரவு வகைகள்:
    • Number: எண்கள் (எ.கா: 25, 3.14)
    • String: உரை சரங்கள் (எ.கா: "தமிழ்நாடு")
    • Boolean: உண்மை/பொய் (true, false)
3

செயற்குறிகள்

Operators in JavaScript
  • • கணிதச் செயற்குறிகள்: +, -, *, /, %, ++, --
  • • ஒப்பீட்டுச் செயற்குறிகள்: ==, ===, !=, >, <, >=, <=
  • • தருக்கச் செயற்குறிகள்: && (AND), || (OR), ! (NOT)
  • • நிபந்தனைச் செயற்குறி: ?: (Ternary Operator)
4

உரையாடல் பெட்டிகள்

Dialog Boxes (Alert, Prompt, Confirm)
  • • alert(): பயனருக்கு எச்சரிக்கை/செய்தி காட்ட உதவும்.
  • • prompt(): பயனரிடமிருந்து உள்ளீட்டை (Input) பெற உதவும்.
  • • confirm(): OK / Cancel என சரிபார்க்க உதவும்.
5

தேர்ந்தெடுப்புக் கூற்றுகள்

Branching (if, else, switch)
  • • if கூற்று: நிபந்தனை மெய்யானால் இயங்கும்.
  • • if...else: மெய்/பொய் இரு நிலைகளிலும் இயங்கும்.
  • • switch...case: பல தேர்வுகளில் ஒன்றை தேர்ந்தெடுக்க உதவும்.
6

சுழற்சி / மடக்குக் கூற்றுகள்

Loops (for, while, do-while)
  • • for மடக்கு: எண்ணிக்கை முன்பே தெரிந்தால் பயன்படும் (தொடக்க மதிப்பு, நிபந்தனை, மிகுப்பு).
  • • while: நுழைவு சோதிப்பு மடக்கு (Entry-check loop).
  • • do...while: வெளியேறு சோதிப்பு மடக்கு (Exit-check loop - ஒரு முறையாவது இயங்கும்).

11-ஆம் வகுப்பு பாடநூல் செய்முறைப் பயிற்சிகள் (Lab Exercises)

பள்ளி செய்முறைத் தேர்வில் கேட்கப்படும் மாதிரி நிரல்கள், தர்க்க விளக்கம் மற்றும் நேரடி இயக்கம்.

செய்முறை 1 for loop

காரணீயம் காணுதல் (Factorial of a Number)

ஒரு குறிப்பிட்ட முழு எண்ணிற்கான காரணீயத்தைக் (n!) கணக்கிடும் ஜாவாஸ்கிரிப்ட் நிரல்.

சூத்திரம்: 5! = 5 × 4 × 3 × 2 × 1 = 120
செய்முறை 2 for loop

பெருக்கல் வாய்ப்பாடு (Multiplication Table)

பயனர் கேட்கும் எந்த ஒரு எண்ணிற்கும் 1 முதல் 10 வரை வாய்ப்பாடு அட்டவணை தயாரித்தல்.

வெளியீடு: 7 × 1 = 7 ... 7 × 10 = 70
செய்முறை 3 if...else & %

ஒற்றை / இரட்டை எண் சோதனை (Odd or Even)

வகுமீதி செயற்குறி (%) பயன்படுத்தி ஒரு எண் இரட்டைப்படையா அல்லது ஒற்றைப்படையா என அறிதல்.

தர்க்கம்: (n % 2 == 0) எனில் இரட்டைப்படை எண்
செய்முறை 4 Nested if / &&

மூன்று எண்களில் பெரிய எண் (Largest of 3)

மூன்று எண்களைப் பயனரிடமிருந்து பெற்று ஒப்பீட்டுச் செயற்குறி மூலம் மிகப்பெரிய எண்ணை தீர்மானித்தல்.

தர்க்கம்: if(a > b && a > c) => a பெரியது
