def linear_search(arr, target):
for i in range(len(arr)):
if arr[i] == target:
return i # எண் கண்டறியப்பட்டது! சுட்டி (Index) திருப்பப்படும்
return -1 # பட்டியல் முழுவதும் தேடியும் கிடைக்கவில்லை

நேரியல் தேடல் எப்படி இயங்குகிறது?

1

வரிசைப்படுத்தல் தேவையில்லை: எண்கள் ஏறுவரிசையிலோ, இறங்குவரிசையிலோ அல்லது எவ்வித வரிசையுமின்றியோ (Unsorted) இருக்கலாம்.

2

முதல் எண்ணில் தொடங்குதல்: சுட்டி i = 0 முதல் தொடங்கி, ஒவ்வொரு உறுப்பாக நேரியல் வரிசையில் (ஒன்றன் பின் ஒன்றாக) பரிசோதிக்கிறது.

3

இலக்கு எண்ணுடன் ஒப்பீடு: நடப்பு எண் தேடும் எண்ணுடன் (target) பொருந்தினால் உடனே அதன் Index [i] திரும்ப அனுப்பப்பட்டு தேடல் நிறைவடையும்.

4

கடைசி வரை தேடல்: இறுதி உறுப்பு வரை சென்றும் எண் கிடைக்கவில்லை என்றால், -1 வழங்கப்பட்டு எண் இல்லை என அறியப்படும் (Time: O(n)).

குறைந்த எண்ணிக்கையிலான அல்லது வரிசைப்படுத்தப்படாத தரவுகளுக்கு எளிய நேரடி வழிமுறை இதுவாகும்!
