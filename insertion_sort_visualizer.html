செருகு வரிசையாக்கம் (Insertion Sort) Worst: O(n²) Best: O(n) Space: O(1)

Python நிரல் (Source Code)

நேரலை வரி கண்காணிப்பான்
def insertion_sort(arr):
for i in range(1, len(arr)):
key = arr[i] # செருக வேண்டிய முக்கிய எண்
j = i - 1
while j >= 0 and arr[j] > key:
arr[j + 1] = arr[j] # வலதுபுறம் நகர்த்துதல்
j -= 1
arr[j + 1] = key # சரியான இடத்தில் செருகுதல்
return arr

செருகு வரிசையாக்கம் எப்படி இயங்குகிறது?

1

சீட்டுக்கட்டு உதாரணம் (Playing Cards Analogy): கையில் உள்ள சீட்டுகளை வரிசைப்படுத்துவது போல, வரிசையின் முதல் உறுப்பு (arr[0]) ஏற்கனவே வரிசைப்படுத்தப்பட்டதாகக் கருதப்படுகிறது.

2

முக்கிய எண் (Key Element): சுட்டி i = 1 முதல் தொடங்கி, நடப்பு எண்ணை key ஆக எடுத்துக்கொண்டு தனியே சேமித்து வைக்கிறது.

3

வலதுபுறம் நகர்த்துதல் (Shifting Elements): முந்தைய வரிசைப்படுத்தப்பட்ட பகுதியில் உள்ள எண்கள் key-ஐ விட பெரியதாக இருக்கும் வரை, அவை ஒரு இடம் வலதுபுறமாக நகர்த்தப்பட்டு இடம் ஏற்படுத்தப்படும்.

4

சரியான இடத்தில் செருகுதல் (Insertion): தகுதியான இடம் கிடைத்ததும், key எண் arr[j + 1]-இல் செருகப்பட்டு அந்தப் பகுதி வரிசையாக்கப்படும்.
