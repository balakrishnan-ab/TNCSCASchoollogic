விரைவு வரிசையாக்கம் • பிரித்து ஆளுதல் முறை (Divide and Conquer)

பிரித்து ஆளுதல் (Lomuto Partition) Average: O(n log n) Worst: O(n²) Space: O(log n)

Python நிரல் (Source Code)

நேரலை வரி கண்காணிப்பான்
def partition(arr, low, high):
pivot = arr[high] # இறுதி எண் மையப்புள்ளி
i = low - 1 # சிறிய எண்களுக்கான சுட்டி
for j in range(low, high):
if arr[j] < pivot:
i += 1
arr[i], arr[j] = arr[j], arr[i] # இடமாற்றம்
arr[i + 1], arr[high] = arr[high], arr[i + 1]
return i + 1 # Pivot-ன் சரியான இடம்
def quick_sort(arr, low, high):
if low < high:
pi = partition(arr, low, high)
quick_sort(arr, low, pi - 1) # இடது பகுதி
quick_sort(arr, pi + 1, high) # வலது பகுதி

விரைவு வரிசையாக்கம் எப்படி இயங்குகிறது?

1

மையப்புள்ளி (Pivot) தேர்வு: வரிசையின் குறிப்பிட்ட ஒரு எண் (பொதுவாக கடைசி எண் arr[high]) Pivot-ஆக தேர்வு செய்யப்படுகிறது.

2

பகுத்தல் (Partitioning): j சுட்டி மூலம் Pivot-ஐ விட சிறிய எண்கள் கண்டுபிடிக்கப்பட்டு, அவை i சுட்டியின் உதவி கொண்டு வரிசையின் இடது பக்கத்திற்கு இடமாற்றம் செய்யப்படுகின்றன.

3

Pivot-ன் சரியான இடம் (Fixed Position): அனைத்து ஒப்பீடுகளும் முடிந்ததும், Pivot எண் அதன் சரியான இடத்தில் (i + 1) நிலைநிறுத்தப்படும். இனி இந்த எண்ணை மாற்றத் தேவையில்லை!

4

தற்சுழற்சி (Recursion): Pivot-க்கு இடதுபுறம் உள்ள பகுதிக்கும், வலதுபுறம் உள்ள பகுதிக்கும் இதே செயல்முறை மீண்டும் தற்சுழற்சியாக (Recursive) பயன்படுத்தப்பட்டு முழு வரிசையும் வரிசைப்படுத்தப்படுகிறது.

பெரிய தரவுத் தொகுதிகளுக்கு நடைமுறையில் மிகவும் பயன்படும் வேகமான அல்காரிதம் (Average: O(n log n))!
