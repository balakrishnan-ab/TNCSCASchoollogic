இனக்குழுக்கள் மற்றும் பொருள்கள் (Classes & Objects)

பொருள்நோக்கு நிரலாக்கத்தின் (OOP) மிக முக்கியமான அடித்தளம் இனக்குழு மற்றும் பொருள் ஆகும். நிஜ உலகச் சூழல்களை கணினியில் மாதிரியாக்கம் செய்ய இவை பயன்படுகின்றன.

திட்ட வரைபடம் (Blueprint)

இனக்குழு என்றால் என்ன? (Class)

பயனர் வரையறுத்த தரவு வகை (User-Defined Type)
  • • இது பொருள்களை உருவாக்குவதற்கான மாதிரி வரைபடம் (Blueprint) ஆகும்.
  • • இனக்குழுவை அறிவிக்கும் போது அதற்கு கணினியின் முதன்மை நினைவகத்தில் (RAM) இடம் ஒதுக்கப்படுவதில்லை.
  • • இது தரவு உறுப்புகள் (Data Members) மற்றும் உறுப்புச் செயற்கூறுகளை (Member Functions) ஒன்றாக இணைக்கிறது.
  • • தொடரியல்: class ClassName { access_specifier: ... };
உயிர்ப்புள்ள சான்று (Instance)

பொருள் என்றால் என்ன? (Object)

இனக்குழுவின் சான்று (Instance of a Class)
  • • ஒரு இனக்குழுவின் அடிப்படையில் தோற்றுவிக்கப்படும் நடைமுறை வடிவம் (Instance) பொருள் எனப்படும்.
  • • ஒரு பொருள் தோற்றுவிக்கப்படும் போதுதான் அதற்கு நினைவகம் (Memory) ஒதுக்கப்படுகிறது.
  • • ஒரே இனக்குழுவை அடிப்படையாகக் கொண்டு பல பொருள்களை தனித்தனி மதிப்புகளுடன் உருவாக்க முடியும்.
  • • புள்ளி செயற்குறி (.) கொண்டு உறுப்புகளை அணுகலாம்: s1.getData();

ஊடாடும் நினைவகக் காட்சிப்படுத்தி (Class Blueprint vs Living Objects)

இனக்குழு என்பது திட்ட வரைபடம் மட்டுமே; 'பொருளை உருவாக்கு' பொத்தானை அழுத்தி கணினியின் நினைவகத்தில் (RAM) பொருள்கள் எவ்வாறு தனித்தனி முகவரியுடன் உருவாகின்றன என்பதைக் கண்கூடாகக் காணுங்கள்!

Student.h (Class Blueprint) 0 Bytes (No RAM used) 
class Student {
private:
    int rollNo;
    string name;
    int mark1, mark2;

public:
    // ஆக்கி (Constructor)
    Student(int r, string n, int m1, int m2);
    int getTotal();
    void bonusMarks(int b);
};
