பைத்தானில் C++ நிரல்களை இறக்கம் செய்தல் (Importing C++ in Python)

பைத்தானின் எளிமை மற்றும் வேகமான உருவாக்கத் திறனையும், C++ மொழியின் அதிவேகச் செயலாக்கத் திறனையும் (Compiled Speed) sys, os மற்றும் getopt கூறுகள் மூலம் ஒன்றிணைக்கும் நுட்பம்.

கீழே உள்ள எந்தவொரு பாடத் தலைப்பையும் தொட்டால் (Click), அதன் எளிய விளக்கம், நிஜ உலக ஒப்புமை, பொதுத்தேர்வுக் குறிப்புகள் மற்றும் நேரடி நிரல் திறக்கும்!
3 பிரிவுகள் • 12 தலைப்புகள்

பைத்தான் வழியாக C++ இயங்கும் விதம் & getopt() காட்சி உருவகப்படுத்தி

கட்டளை வரியில் (Command Prompt) உள்ளிடப்படும் கட்டளை எவ்வாறு sys.argv மற்றும் getopt.getopt() மூலம் பிரிக்கப்பட்டு, g++ வழி தொகுக்கப்பட்டு இயங்குகிறது என்பதைப் பாருங்கள்!

1. கட்டளை வரி (Command Line) & sys.argv / getopt() பகுப்பாய்வி

C:\Python3>
sys.argv பட்டியல் (Command-Line Arguments List) len(sys.argv) = 3

sys.argv[0] எப்போதும் இயக்கப்படும் பைத்தான் நிரலின் பெயரைக் கொண்டிருக்கும்; sys.argv[1:] பயனர் அனுப்பும் அளபுருக்களைக் கொண்டிருக்கும்.

getopt.getopt(argv, "i:o:", ["ifile=", "ofile="]) Returns (opts, args)
opts (Option, Value Pairs):
[('-i', 'palindrome')]
Generated OS Commands:
g++ palindrome.cpp -o palindrome.exe

4-படிநிலை செயலாக்க ஓட்டம் (4-Stage Execution Flow):

Step 1
Python CLI படித்தல்

sys.argv மற்றும் getopt மூலம் C++ கோப்பின் பெயரைப் பெறுதல்.

Step 2
MinGW g++ தொகுத்தல்

os.system('g++ file.cpp -o file.exe') மூலம் தொகுத்தல்.

Step 3
.exe கோப்பு உருவாக்கம்

இயந்திர மொழிக்கு மாற்றப்பட்ட .exe கோப்பு உருவாக்கப்படுதல்.

Step 4
வெளியீடு பெறுதல்

os.system(exe_file) கட்டளை C++ வெளியீட்டைத் திரையில் காட்டுதல்.

// Click "Run Pipeline" above to watch Python compile and run C++!
சிறப்பு மாறி (Special Variable)

if __name__ == "__main__": எவ்வாறு செயல்படுகிறது?

ஒவ்வொரு பைத்தான் நிரலுக்கும் __name__ என்ற உள்ளமைந்த மாறி உண்டு. நிரலை நேரடியாக இயக்கினால் அதன் மதிப்பு "__main__" ஆக இருக்கும்; வேறொரு நிரலில் import செய்தால் கோப்பின் பெயராக இருக்கும்.
