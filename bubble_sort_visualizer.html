இடமாற்று வரிசையாக்கம் (Comparison Sort) Time: O(n²) Space: O(1)

Python நிரல் (Source Code)

நேரலை வரி கண்காணிப்பான்
def bubble_sort(arr):
n = len(arr)
for i in range(n):
swapped = False
for j in range(0, n - i - 1):
if arr[j] > arr[j + 1]:
arr[j], arr[j + 1] = arr[j + 1], arr[j] # இடமாற்றம்
swapped = True
if not swapped:
break # வரிசையாகிவிட்டால் முன்கூட்டியே முடிக்கும்
return arr

குமிழி வரிசையாக்கம் எப்படி இயங்குகிறது?

1

அடுத்தடுத்த எண்களை ஒப்பிடுதல்: வரிசையின் முதல் எண்ணில் தொடங்கி, அருகிலுள்ள அடுத்த எண்ணுடன் (arr[j] மற்றும் arr[j+1]) ஒப்பிடப்படும்.

2

இடமாற்றம் (Swapping): முதல் எண் அடுத்த எண்ணை விட பெரியதாக இருந்தால் (>), அவை இரண்டும் தங்களின் இடங்களை மாற்றிக்கொள்ளும்.

3

பெரிய எண் கடைசியில் சேருதல்: நீர்க்குமிழி மேல் எழுவது போல, ஒவ்வொரு சுற்றின் முடிவிலும் அந்த சுற்றின் மிகப்பெரிய எண் வலதுபுறக் கடைசியில் நிலைபெறும் (பச்சை நிறம்).

4

செழுமைப்படுத்தப்பட்ட நிறுத்தம்: எந்தவொரு சுற்றிலும் ஒரு மாற்றமும் நிகழவில்லை என்றால், எண்கள் ஏற்கனவே வரிசையாக உள்ளன என அறிந்து சுழற்சி முன்கூட்டியே நிறுத்தப்படும்.

கற்பதற்கும் புரிந்து கொள்வதற்கும் எளிமையான தொடக்க வரிசையாக்க அல்காரிதம் இதுவாகும்!
